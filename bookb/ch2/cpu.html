3. Cache Eviction Mechanics (How Old Memory Clears)

Automatic Eviction (LRU Algorithm) vs. Manual Clear Button

Cache has no physical button in hardware. When full, the CPU automatically uses an Eviction Algorithm (e.g., LRU - Least Recently Used) to kick out the oldest data block back to RAM to make space for new incoming data! You can also use the Manual Flush button to see how software clears cache.
